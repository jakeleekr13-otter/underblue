# 추가 참조 이미지 확인 — 2026-09-29

`DeveloperMedia/eval/market/Sea_thru_before_after`의 before/after 8쌍과
`DeveloperMedia/eval/aquacolorfix`의 O/A 5쌍을 모두 확인했다.
각 원본·현재 `combined` 결과·목표를 나란히 보고, Sea-thru 8장은 이전 코드
`eb0b7a4`와 현재 소스 양쪽으로 새로 렌더링했다. AquaColorFix는 동일한 현재 코드로
이미 실행한 `m5-final2-aqua-20260929` 결과를 사용했다. 시뮬레이터는 사용하지 않았다.

**결론: m5 개선이 다양한 수중 장면의 자연스러운 색 복원으로 일반화됐다고 볼 수 없다.**
이번 밝은 파란 물/reference 보정의 적용 범위 밖에서는 청록색 잔여와 부족한 따뜻한
색 복원이 그대로 남는다. 이 확인에서는 보정 코드를 추가로 변경하지 않았다.

700px 원본 크기를 유지했다. Natural, intensity 0.8, sRGB PNG로 평가했다.
Photo 평균 색차는 30.747→30.458, 일정 깊이 `uniform`은 31.146→30.785이다.
Photo에서 02·06만 의미 있게 바뀌고 나머지는 표시 정밀도에서 같다.
01·03·04·05·07은 목표보다 평균 L*가 약 16–20 높다. 08은 36.9 대 목표 37.0이다.

이 수치는 **참고용**이다. 기사에서 위/아래로 잘라낸 이미지이며 일부에는 흰 경계선,
워터마크, 다른 자막과 프레이밍 차이가 보인다. 현재 도구는 정합·콘텐츠 마스크 없이
전체 픽셀을 비교한다. 따라서 특히 06의 색차를 기존 m5의 17.25와 직접 비교하거나,
절대 색차를 합격선으로 사용하면 안 된다. 다음 정량 gate에는 정합과 자막/경계 제외가 필요하다.

## AquaColorFix

| 번호 | 현재 결과와 A 이미지의 주요 차이 |
|---|---|
| 1 | 물의 전체 방향은 가깝다. 오른쪽 암초는 현재가 더 분홍·연보라색이고, 물고기와 밝은 영역도 더 밝게 보인다. |
| 2 | 물은 비슷한 파란색 계열이다. 물고기는 현재가 회색에 가깝고, 목표의 노란색·따뜻한 색을 충분히 보존하지 못한다. |
| 3 | 개복치 배와 몸에 청록·황록색 잔여가 보인다. 목표는 배가 더 중립적이고 몸의 명암·무늬 구분이 다르다. |
| 4 | 만타 배 일부가 민트색이며 바닥은 올리브·녹색이다. 목표의 배는 더 중립적이고 바닥은 갈색 계열이다. |
| 5 | 물고기 떼는 창백한 청록·회색, 오른쪽 암초는 분홍·연보라색에 가깝다. 목표는 더 따뜻한 물고기와 황갈색 암초다. |

기존 벤치마크 기준 gate(2·4·5)는 photo 12.31→12.27, uniform 12.85→12.82다.
변화는 주로 4번의 작은 개선이며, 다른 쌍의 위 문제를 해결했다는 의미는 아니다.
이 검토의 축소 비교 이미지만으로 노이즈 개선/악화를 새로 판정하지 않았다.
노이즈는 같은 해상도의 무손실 결과와 평탄한 영역에서 별도로 측정해야 한다.

## 후속 평가 우선순위

1. Sea-thru 03의 붉은 갈색, 05·07의 중립적인 판상 산호, Aqua 02의 실제 노란색을
   각각 피사체 색 보존 사례로 삼는다. 모든 피사체를 중립화하는 접근은 피한다.
2. Sea-thru 01의 실제 녹색 산호와 푸르게 남은 바닥을 구분한다. “녹색 감소” 하나로
   성공을 판정할 수 없다.
3. Aqua 04의 배/바닥, 05의 물고기/암초를 각각 별도 영역으로 평가한다.
4. Sea-thru는 정합과 자막·테두리 마스크를 먼저 확정하고, 색상 패널을 포함한 영역별
   지표를 만든다. 06과 m5, 05와 07의 장면 중복도 별도로 표기한다.
