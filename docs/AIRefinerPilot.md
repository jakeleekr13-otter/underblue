# AI 보완 모델 파일럿 결과 — 개발 보류

평가일: 2026-10-08
결정: 독립 AI 프리셋 개발 보류. 기존 보정 경로 유지.

## 결론

1차 보정본과 두 가지 AI 보완본을 13장에서 비교했으나, 사용자는 대부분에서 의미 있는 차이를 느끼지 못했다.

| 선택 | 장수 |
|---|---:|
| 차이 없음 | 8 |
| 약한 보완 | 2 |
| 강한 보완 | 1 |
| 1차 보정본 | 1 |
| 모두 불만족 | 1 |

보완 후보 선택 3장 중 2장의 의견도 “큰 차이는 모르겠다”는 조건부 선택이었다. 독립 검증 2장은 모두 차이 없음이었다. 평가 결과는 현재 AI 보완 모델이 추가 처리·제품 복잡도·별도 유료 기능을 정당화할 만큼 체감되는 이득을 보이지 않았다는 뜻으로 기록한다.

AI 프리셋, 추가 구매 상품, 모델의 앱 번들은 구현하지 않는다. 기존 Core ML 깊이 추정과 Core Image/Metal 보정 경로를 유지한다.

## 시험 구성

- 입력: 기존 프로덕션 Natural 0.8 보정 결과.
- 사진: 총 13장. 학습 8, 검증 2, 평가 3으로 장면 그룹을 분리했다.
- 교사: 공개 NAFNet-SIDD-width32 노이즈 제거 모델.
- 학생 모델: 42,987 파라미터의 작은 동일 해상도 residual CNN.
- 학습: 8장의 1차 보정본에서 교사 출력의 60% 강도를 모방하는 600-step 파일럿.
- 보완 약함: 학생 residual 35%.
- 보완 강함: 학생 residual 75%.
- 화면에서 후보 순서를 사진별로 섞고, 1차 보정/보완 1/보완 2를 동일 크기로 비교했다.
- 학생 모델은 사용자 선택 전에 학습한 교사 모방 파일럿이다. 사용자 취향을 학습한 모델이 아니다.

검증 MSE가 교사 모방 기준으로 identity보다 낮아졌다는 사실은 기록했지만, 이는 사람이 느끼는 품질 개선을 뜻하지 않는다. 최종 판단은 세 이미지 비교 평가를 사용했다.

## 사용자 평가

| 사진 | split | 선택 | 기록 |
|---|---|---|---|
| train-01 | train | 강한 보완 | 큰 차이는 못 느끼겠지만 보완 2의 부유물이 약간 더 작음 |
| train-02 | train | 약한 보완 | 큰 차이는 모르겠지만 보완 1이 아주 약간 더 선명해 보임 |
| train-03 | train | 차이 없음 | |
| train-04 | train | 1차 보정 | 보완 1, 2에서 우측 산호와 물 배경 부위가 너무 진함 |
| train-05 | train | 모두 불만족 | 셋 다 부유물 노이즈가 너무 심함 |
| train-06 | train | 차이 없음 | |
| train-07 | train | 차이 없음 | |
| train-08 | train | 차이 없음 | |
| validation-01 | validation | 차이 없음 | |
| validation-02 | validation | 차이 없음 | |
| evaluation-01 | evaluation | 약한 보완 | 크게 차이 없음 |
| evaluation-02 | evaluation | 차이 없음 | |
| evaluation-03 | evaluation | 차이 없음 | |

학습 대상으로 바꿀 수 있는 결정적 train 선택은 강한 보완 1, 약한 보완 1, 1차 보정 1뿐이다. 검증 선택은 0장이다. 계획했던 최소 조건인 train 2장과 validation 1장의 결정적 선택을 만족하지 못해 선호 미세조정을 실행하지 않았다. 차이 없음·모두 불만족을 임의로 보완 모델의 정답으로 바꾸지 않았다.

## Core AI 산출물

파일럿 학생 모델은 Core AI aimodel로 변환되었다.

- 정적 입력/출력: Float16 RGB, NCHW 1×3×256×256, sRGB 0~1.
- 모델 파일: 92,835 bytes.
- Mac 계산 검증: PyTorch FP16 기준 최대 절대 차이 0.00048828, 출력 유한/0~1.
- Mac M3 단일 256×256 텐서 추론 중앙값: 자동 설정 9.89ms, Neural Engine 선호 0.832ms.
- 이 시간은 타일 준비·전체 사진·최종 혼합·저장 시간을 포함하지 않는다.
- 실제 장치 배치를 Instruments로 확인하지 않았으므로 Neural Engine 선호 시간을 ANE 사용의 증명으로 취급하지 않는다.
- iPhone 시험은 별도 검증 앱으로 준비했지만 최종 제품 판단에는 필요하지 않다. 체감 화질 조건이 먼저 실패했다.

모델 파일과 평가 이미지는 Git 제외 .build/experiments/ai-refiner-v001에 남긴 로컬 실험 산출물이며 앱 타깃에 포함하지 않는다.
